## Contract

- Classify single GitHub SKILL.md / *.skill.md inputs as github_raw and call ingest_skill. Ordinary documents remain single_url/blog. Preserve pinned revisions and existing repository/tree inputs.
- SkillMind is the only distiller and semantic judge. Require its semantic_distillation_v1 capability (v2.5 contract), preserve canonical section titles/item text exactly in the final SE body, and retain legacy non-Skill rendering. No new synthesis or invented numeric quality cutoff.
- AuditResult supports coverage=None, PASS/FAIL/UNKNOWN, needs_human_review, four semantic dimensions, schema/audit versions, complete report details, all matching draft paths, and byte hashes binding the audited draft files. is_approved requires PASS and needs_human_review=false; semantic drafts additionally require all four dimensions PASS. Missing or malformed verdicts stay UNKNOWN.
- Audit only the requested source batch, publish audit inputs through the current Python API into a dedicated per-run staging directory, use configured SkillMind paths (DRAFTS_DIR, get_vault_dir), and persist every failed/unknown source to manual review. No bare skillmind executable, global publish --all, hardcoded home directory, silent successful exit after failure, or lost multi-card draft.
- Before approval require exact correspondence between requested persisted drafts, successfully staged evidence drafts, and report.extract_files. Missing/extra cards, partial staging, changed draft/artifact bytes, or mismatched canonical evidence must return UNKNOWN. Set discovery budget from the scoped artifact count, not an inherited arbitrary card limit. Persist artifact_sha256 and verify before injection alongside draft hashes.
- RoutedSkill carries the complete audit record. Before injection verify approval, source hash, draft bytes and loaded draft equality against the audited snapshot. Stage PASS cannot authorize changed drafts.
- Final Markdown preserves canonical body and receives SE routing frontmatter with type: skill and source-backed trigger.keywords. Bind a new .evidence.json to final bytes with the compatible {artifact_sha256,draft} envelope and sanitized source. Never copy the staging hash. Validate final evidence; ledger and rollback handle Markdown/evidence together, protect foreign/edited files, and undo partial writes.
- Current USER vault rule (role-gene specification §2/§10, updated 2026-10-31) already abolished skill_refs registration on 2026-08-25. Directory plus skill trigger is the only dynamic recall path. Do not add skill_refs or rule_refs, mutate existing genes or create missing genes during distillation. Earlier draft assumption of gene registration is superseded by this existing higher-priority contract. Keep old gene rollback only for recoverable historical entries. Each new skill needs audited nonblank keyword strings and at least one keyword unique in its role directory (excluding itself), as explicitly required by vault §10.4; reject collisions without inventing new keywords. No generic role-name fallback. Preserve canonical meta type inside its evidence, while final artifact type is skill for engine consumption.
- Preflight validates semantic APIs/schema and accepts explicit --vault before importing vault-dependent modules. Align current interpreter/config; document the v2.5 runtime and three-state policy. Version consumer as 0.2.0 for the new contract (feature release, no claim of npm publication).
